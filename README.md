# amazon-price-tracker-2

I got tired of browser extensions phoning home, so I built this. It scrapes
Amazon product pages, stores prices in a local SQLite db, and prints drops to
stdout so I can pipe it to whatever notification system I want.

## install

pip install -r requirements.txt

## usage

the output for "DROPPED" to trigger alerts.
